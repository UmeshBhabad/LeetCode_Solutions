<h2>🛠️ How LeetSync Works</h2>

<ol>
<li>I solve a problem on LeetCode and my solution is accepted</li>
<li>The <a href="https://github.com/LeetSync/LeetSync">LeetSync</a> Chrome extension detects the accepted submission</li>
<li>It fetches the problem's title, description, difficulty, and constraints directly from LeetCode</li>
<li>It creates (or updates) a folder here named <code>&lt;number&gt;-&lt;problem-slug&gt;</code>, containing an auto-generated <code>README.md</code> with the problem statement and my solution file</li>
<li>Everything is pushed to this repository automatically — I don't manually commit individual solutions</li>
<li>A GitHub Action then runs <code>generate_leetcode_index.py</code> automatically, splitting solved problems into the DSA and SQL tables below</li>
</ol>
